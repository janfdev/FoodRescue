# 06: Super Admin Control Center & Impact Analytics

**What to build:**
Web dashboard terpusat untuk tim operasional platform:
- Metrik Utama & Impact Counter:
  - Total Makanan Diselamatkan (Porsi & Estimasi Kilogram).
  - Gross Merchandise Value (GMV) & Pendapatan Komisi Platform (12%).
  - Total Rescue Box B2B Terjual.
  - Jumlah Mitra Aktif vs Toko Bermasalah (Kepatuhan Rendah).
- Moderasi & KYC Mitra Toko:
  - Review pendaftaran toko baru (Foto KTP, Foto Toko, Menu).
  - Aksi: Setujui, Minta Revisi, atau Bekukan Toko (*Suspend/Banned*).
- Manajemen Inventaris B2B Rescue Box:
  - Input nomor resi logistik untuk pengiriman box ke toko mitra.
- Keuangan:
  - Review dan persetujuan transfer penarikan dana (*Withdrawal*) ke rekening mitra.
- Pusat Resolusi Sengketa (Dispute & Chat Log Audit):
  - Membuka riwayat chat Buyer-Seller saat terjadi komplain untuk keputusan refund.
